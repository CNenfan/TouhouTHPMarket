# 芙湘东方高校联合 THP7 活动网站

本仓库是 **芙湘东方高校联合 THP7 活动**使用的线上代币、答题、故事解锁与模拟股市系统。项目按单日线下展会、移动端优先、低服务器成本的方向设计，适合作为社团活动技术组的实现参考。

当前公开版本：`2.5.3`，数据库 schema `v10`。

## 项目定位

- 活动积分系统，不是支付系统、证券系统、博彩系统或数字资产发行系统。
- FDT 只用于活动现场兑换无料、奖品或参与互动，不可充值、提现、转让给外部人员或兑换现金。
- 模拟股市只做娱乐展示，不接入真实证券行情，不构成投资建议。
- 代码公开的目的是方便其他活动主办方理解架构、风控和现场运维方式，不代表可以直接照搬活动品牌、题目、文案或美术。

## 主要功能

### 游客端

- 昵称、密码和图片验证码注册登录，无手机号和邮箱依赖。
- 登录状态持久化，Session 失效后可恢复登录。
- 一设备一号的尽力限制，结合 HttpOnly Cookie、localStorage 与浏览器指纹；网页无法读取真实 MAC，换浏览器或清理数据仍可能绕过，现场需要人工兜底。
- 代币领取、答题奖励、付款码、管理员收款码和用户间转让。
- 六位故事码解锁，支持文字与配图，解锁后可快速跳转。
- 模拟股市：默认公司、游客创建公司、买卖、持仓、盈亏、资产榜、股票盈亏榜、新闻与天狗快讯。
- 银行借款、利息、还款、消费限制、转让限额与交易频率限制。
- 手机与桌面端适配，全站通知和股市新闻支持未读弹窗。

### 管理员端

- 发币、收币、代币码与二维码管理。
- 用户余额、借款、封禁、权限、设备风险和批量操作。
- 题目、故事、公司、新闻模板和已发布内容管理。
- 行情查看、自动生成、人工修改、AI 修改、导入导出与看板展示。
- 参数设置、活动数据重置、测试账号清理和一次性运维脚本。

## 技术栈

- PHP 8.2
- MySQL 8 或 MariaDB 10.6 以上
- 原生 HTML、CSS、JavaScript，无前端构建步骤
- PDO MySQL、GD、mbstring、curl、OpenSSL
- 可选 OSS 静态资源前缀，前端加载失败时回退服务器本地图片
- 可选 OpenAI 兼容接口，默认示例为 DeepSeek

## 目录结构

```text
public/                     网站根目录
  index.php                 页面入口与初始配置注入
  api.php                   JSON API 入口
  install.php               首次安装向导，安装后必须删除
  schema.sql                数据库建表与示例数据
  config.sample.php         配置模板
  includes/                 认证、交易、行情、新闻、后台逻辑
  assets/                   本地 CSS、JS、图片和二维码库
  data/                     行情、缓存、备份等运行时数据，需要可写
  uploads/                  故事与活动图片，需要可写
docs/                       部署与运维说明
tools/                      迁移、压测、部署和走势工具
```

`public/config.php`、`public/data/`、`public/uploads/`、现场题库、二维码和个人数据均不进入公开仓库。

## 快速开始

1. 准备一个空 MySQL 数据库，字符集使用 `utf8mb4`。
2. 将 Web 服务器站点根目录指向 `public/`。
3. 复制配置模板：

```bash
cp public/config.sample.php public/config.php
```

4. 编辑 `public/config.php`，填写数据库、站点地址和可选 AI Key。所有密钥只保存在服务器，不得提交到 Git。
5. 访问 `https://example.com/install.php` 完成建库和管理员初始化，或手动导入 `public/schema.sql` 后创建管理员。
6. 确认 `public/data/` 与 `public/uploads/` 对 PHP 运行用户可写。
7. 安装完成后立即删除 `public/install.php`，并修改默认管理员密码。
8. 启用 HTTPS，配置每日数据库备份与站点文件备份。

本地开发可以运行：

```bash
php -S 127.0.0.1:8123 -t public
```

## 关键配置

配置模板位于 `public/config.sample.php`。生产环境至少应确认：

- `db`：数据库地址、库名、最低权限账号与强密码。
- `base_url`：对外 HTTPS 地址，用于二维码与打印链接。
- `auth_remember_days`：登录保持天数。
- `deepseek.key`：AI Key，仅写入服务器 `config.php`。
- `oss_base_url`：可选 OSS 前缀；失败时前端回退本地资源。
- `timezone`：默认 `Asia/Shanghai`。

备案信息通过数据库设置项 `icp_number`、`police_beian`、`police_code` 提供。公开仓库不包含任何真实备案号；运营方必须使用自己依法取得的备案信息。

## 部署安全

- 禁止把 `config.php`、数据库密码、AI Key、FTP 密码、SSH 私钥或备份 SQL 提交到 Git。
- `public/data/` 和 `public/uploads/` 禁止执行 PHP。
- 上传目录只允许图片类型，并限制文件大小与文件名。
- 管理后台必须使用强密码；有条件时增加 IP 白名单、双因素认证或独立后台域名。
- 生产数据库账号只授予业务所需权限，不要使用 root。
- Nginx 示例：

```nginx
location ~ ^/(data|uploads)/.*\.php$ {
    deny all;
}
```

## 备份与恢复

活动结束后至少保留以下内容：

- 数据库全量 SQL 快照。
- `public/data/` 与 `public/uploads/`。
- 服务器版 `config.php`。
- 当前代码快照与版本号。
- 奖券、兑换记录、异常处理和人工调整记录。

恢复前先在隔离环境验证 SQL 可导入、图片路径可访问，再切换正式站点。数据库备份含密码哈希、登录令牌和用户 IP，必须按敏感数据保管。

## 已知边界

- 设备限制不是硬件级 MAC 绑定，不能阻止所有换设备或清缓存行为。
- 前端输入、二维码和摄像头功能受浏览器权限影响，现场应准备手动六位码方案。
- 模拟股市和 AI 走势只用于娱乐展示，不应对参与者承诺收益。
- 支付码、发币码和故事码必须现场人工核验，发现异常应及时冻结。
- 本项目未附带默认生产参数保证。上线前应完成并发压测、备份演练和回滚演练。
